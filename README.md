# Vulkan Game Engine

A custom 3D game engine built from scratch using **C++** and the **Vulkan API**. This project is currently in development as part of a deep dive into low-level graphics programming, memory management, and modern engine architecture.

## Overview
This repository documents my journey in building a high-performance graphics engine. The core architecture is heavily inspired by Brendan Galea's Vulkan tutorial series, focusing on understanding the rendering pipeline and modern C++ practices rather than just utilizing a pre-built framework.

## Tech Stack
* **Language:** C++17 / C++20
* **Graphics API:** Vulkan
* **Windowing:** GLFW
* **Mathematics:** GLM (OpenGL Mathematics)
